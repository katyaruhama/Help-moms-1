# Мамам рядом

Landing page на русском языке для проекта помощи мамам после родов. Страница подходит для GitHub Pages и работает как статичный MVP: посетители выбирают сценарий для мамы или помощника, видят примеры заявок, фильтруют типы помощи и могут подготовить письмо через форму.

## Что внутри

- `index.html` — готовая страница со стилями и небольшим JavaScript.
- Форма открывает черновик письма через `mailto`.
- На странице есть блоки для двух аудиторий, примеры коротких задач, FAQ и карточки заявок с кнопками отклика.
- Первый экран использует изображение с Pexels CDN, а карточки помощи сделаны текстовыми, чтобы сайт оставался лёгким и понятным.

## Перед публикацией

1. В `index.html` замените `hello@example.com` на реальный email проекта.
2. При необходимости замените примеры заявок на реальные тексты.
3. Для полноценного сервиса подключите форму к Google Forms, Airtable, Supabase, Firebase или собственному backend.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите `index.html` и `README.md` в корень репозитория.
3. Откройте `Settings` -> `Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Укажите ветку `main` и папку `/root`, затем нажмите `Save`.
6. Через несколько минут GitHub Pages покажет публичную ссылку.
